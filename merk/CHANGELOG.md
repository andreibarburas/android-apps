# Changelog

All notable changes to Merk are documented here.

## [1.1.1] - 2026-07-12

- ✨ New: link to the r/BarburasLab community subreddit in Settings > Support

---

## [1.1.0] - 2026-07-08

At BARBURAS, all apps share the same design language and fonts are a big part of that. This update brings Merk in line with the rest of the suite.

- ✨ New: optional font pairing in Settings > Display — DM Serif Display for headings, Inter Tight for all UI text. Toggle it on and see how it feels.

---

## [1.0.7] - 2026-06-23

- ✨ New: bookmark list now shows favicons fetched from your Nextcloud server, with a coloured initial avatar as fallback
- 🐛 Fixed: back button and swipe-back gesture now correctly dismiss the Add/Edit bookmark screen
- 🐛 Fixed: saving a bookmark dismisses the keyboard first, so the "Bookmark saved" confirmation is visible before navigating back

---

## [1.0.4] - 2026-06-14

- 🐛 Fixed: Login Flow v2 poll URL rewriting for Tailscale and reverse-proxy/subdomain setups — prevents "failed to connect" errors and login hangs
